YSC CARPET - TAM B2B WEB SİTESİ + ADMIN

Gereksinim: PHP 8+ ve MySQL.
Kurulum:
1) ZIP'i hosting'e yükle ve aç.
2) Tarayıcıdan siten.com/install.php adresini aç.
3) Hosting firmasının verdiği MySQL bilgilerini gir.
4) Admin kullanıcı adı/şifreni belirle.
5) Kurulum bitince siten.com/admin/login.php adresinden gir.
6) Güvenlik için install.php dosyasını sil.

Admin:
Dashboard / Ürünler / Koleksiyonlar / Site Ayarları.
Ürünlerde: fotoğraf, kod, ölçü, stok, fiyat, açıklama, koleksiyon, Spot & Outlet, yayında/gizli, öne çıkan.

Klasörler:
images/logo/
images/hero/
images/spots/
uploads/
database/

Logo: images/logo/logo.png koyabilirsin.
Hero: images/hero/hero.jpg koyabilirsin; placeholder SVG'yi değiştirmek için style.css içindeki yolu güncelleyebilirsin.
