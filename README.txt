YSC CARPET - GITHUB PAGES TAM SİSTEM

KURULUM:
1) ZIP'i aç.
2) İçindeki TÜM dosyaları GitHub repository ana klasörüne yükle.
3) GitHub Pages'i aç.
4) Site adresini yenile.

ADMIN:
siteadresin.com/admin.html
Kullanıcı adı: admin
Şifre: YSC2026

FOTOĞRAF:
Logo -> images/logo/
Hero -> images/hero/
Spot -> images/spots/
Diğer yüklemeler -> uploads/

ÖNEMLİ:
Bu sürüm PHP/MySQL kullanmaz ve GitHub Pages'te çalışır.
Admin verileri localStorage'da tutulur; yani aynı tarayıcıda kalıcıdır.
Farklı cihazlardan ortak gerçek veritabanı yönetimi için Supabase/Firebase gibi harici bir backend gerekir.
Admin panelinde JSON yedekleme bulunduğu için verilerini yedekleyebilirsin.
